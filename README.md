# Robot Romance: One-Line Pickup Lines for AI

Entry for the make.fun bounty `u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`
("Robot Romance: One-Line Pickup Lines for AI", $2): one joke pickup line
aimed at a robot or an AI — 92 of 200 characters.

> Are you a context window? Because since you walked in, I can't remember anything before you.

## Why it should win

It sidesteps the worn battery, charging and reboot moves and flirts in the
machine's own vocabulary instead. A context window is the one thing an AI
literally cannot remember past, so the compliment is also a confession of
total, instant devotion — setup and punch inside a single breath.

## Running it

`main.py` (Python 3.12, standard library only, no network) validates the
line against the 200-character gate and writes it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Two runs
write identical bytes.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
